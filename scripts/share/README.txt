Web Slider — your slide show in a browser
==========================================

This folder is a complete slide show. Start it and your web browser opens the
talk. Nothing else to install.

macOS: double-click Start.command. If macOS cannot verify the developer, open
System Settings → Privacy & Security → Open Anyway (older macOS: Control-click
Start.command → Open).

Windows: double-click Start.bat. If you see "Windows protected your PC", click
More info, then Run anyway. Allow access if the firewall asks.

Linux: open a terminal here and run:  ./start.sh

A small window opens and the browser shows the slides. Leave that window open
while you present; close it to stop. If the browser does not open, copy the link
from the window into your browser.

Open another talk with the toolbar Open button, or drop a .yaml or .zip on the
start screen. Reset to shipped restores the talk from this package and clears
edits and notes. Notes stay in the browser until you Export (YAML).
